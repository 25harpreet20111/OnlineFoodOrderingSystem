# 🍽️ GourmetGo – Online Food Ordering System Website

**GourmetGo** is a full-stack food ordering web application that allows users to browse food items, search by category, add items to a cart, and place orders through a simple and responsive interface.

## 🚀 Features

* 👤 User Registration & Login
* 🍔 Browse Food Menu
* 🔍 Search & Category Filtering
* 🛒 Shopping Cart
* 📦 Order Placement & Confirmation
* 📱 Responsive Design
* 🗄️ Database Management

## 🛠️ Technologies Used

* **Frontend:** React.js
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Languages:** JavaScript, HTML, CSS
* **Tools:** Git & GitHub

## 🏗️ Project Architecture

React.js → Express.js / Node.js → MongoDB
Frontend       Backend             Database
```

Configure your MongoDB connection in the `.env` file before running the application.

## 🎯 Objective

To develop a modern, user-friendly online food ordering platform while demonstrating full-stack web development, REST API integration, database connectivity, and responsive UI design.
